# 見本

`showcase.png` は、この言語で書いた1つの文書を実際に描画したものです。
構文がどう見えるかを一目で確かめるためのもので、テストではありません。

元のソースは `showcase_test.dart` の `_source` にあります。

## 何が写っているか

| 見えるもの | 書いたもの |
|---|---|
| 大きい見出し | `:++:*:%natural_block::` |
| `C++` `100%` `Really?!` `you@example.com` | そのまま。エスケープなし |
| 赤・緑・太字 | `:!` `:%` `:*` |
| 文中の等幅の `<` `=` `>` `^` | `` `<` `` などと書いた、文中の区間 |
| 枠付きのコード | 改行を含む区間 |
| 罫線付きの表 | `~` で宣言。価格は右寄せ、在庫は中央 |
| 更新日が左、日付が右 | `^更新日^^>2026-09-02^` — 空セルが押し出している |

同じ `` ` `` という構文が、**改行を含めば枠付きのブロック、1行なら等幅のラン**として
描き分けられているのが見どころです。

## 描き直す

```bash
flutter test test/showcase --update-goldens
```

Windows のフォントを直接読むので、それ以外の環境では自動的に skip されます。
